# Staging files

You may stage files on the C2 for public download via navigating to: `Upload`.

Simply select your file, the URI you wish it to be downloaded from, and the file name to be downloaded, and upload! You can view
your staged files from the nav menu also from: `Preparation -> View staged resources`.
