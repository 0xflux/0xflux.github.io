# Loot

The C2 currently has a maximum file upload limit of 10 GB. Considerations to make this more malleable will be made in
the future.

Loot you exfiltrate on an engagement gets stored in the C2 Docker container at `/data/loot/`. You can then find loot indexed
by the machine's **hostname**.
